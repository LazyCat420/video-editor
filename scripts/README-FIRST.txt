VIDEO EDITOR - How to start
===========================

1. Copy this whole folder to your computer (for example, onto the Desktop).
   Keep everything together in the one folder.

2. Open the folder and double-click:  video-editor.exe

3. The first time, Windows may show a blue box that says
   "Windows protected your PC".

   This appears because the program does not have a paid certificate.
   To continue:

       Click  "More info"       (small text in the blue box)
       Click  "Run anyway"      (button that then appears)

   You should only need to do this once.


If the program does not open at all
-----------------------------------
Windows Security may have quarantined it. Open Windows Security,
go to "Virus & threat protection" -> "Protection history", find
video-editor.exe, and choose "Restore" / "Allow on device".


Do NOT move these out of the folder
-----------------------------------
   assets\    - the stickers and pictures the program uses
   bin\       - the video engine (FFmpeg) the program needs

Without these the program will open but cannot load or save videos.
